DevSecOps Scorecard is a FastAPI application that helps developers and engineering teams evaluate repository security using practical DevSecOps controls. By combining GitHub repository analysis with a structured scoring model, the application provides a fast and consistent way to identify security gaps and improve repository readiness before deployment.
