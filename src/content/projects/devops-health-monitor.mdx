  "I wanted a way to know, in real time, whether the tools I depend on daily, GitHub, Docker Hub, Azure, Cloudflare, Google Cloud, and AWS, were actually up and responding quickly, rather than finding out only when something broke. approach: [
  "Built a FastAPI backend that sends live HTTP requests to each of the six services every 10 seconds and measures response times against defined thresholds. No simulated data is used. If a service is slow or unreachable, the dashboard flags it based on the actual response. The app is containerized with Docker and runs across three environments, local, dev, and production. Each environment has its own badge on the dashboard so it is clear which environment is being viewed. Infrastructure is defined in Terraform, provisioning an Azure Container Registry and App Service for the dev and production environments. Deployments are handled through two separate pipelines, one in GitHub Actions and one in Azure DevOps, each using Test, Build, and Deploy stages."
